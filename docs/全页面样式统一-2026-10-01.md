# 全页面样式统一核验

采用 shadcn/ui 官方 Button 的 default / outline / ghost / destructive 操作分级，适配为项目内原生 CSS 组件；没有安装完整 shadcn、Radix 或 Tailwind，也没有复制其源码。
参考：https://ui.shadcn.com/r/styles/new-york/button.json

共享组件：src/shared/ui/button/Button.tsx。
共享设计变量与页面适配：src/layouts/workbench/theme.css，在基础与工作台样式后加载，优先级覆盖延迟加载的插件样式。

已迁移 32 个组件中的操作按钮，并覆盖表单、表头、卡片、导航、状态与弹窗外观。页面导航、列表选择与下载链接保留语义元素，由共享样式统一。危险操作保留红色，代码差异和警告保留语义颜色。

浏览器检查：项目概览、翻译内容、任务、审核、导出、版本、术语、资源、脚本、协议、引用；项目库、关于；插件的补丁管理、桥接与预设、离线工具、补丁说明；设置弹窗；预设转换和提示词编辑。
空数据页面核验了空态，不能替代全部复杂内容状态。正则覆盖、正则编辑、命名空间和路由弹窗已做组件源码迁移和构建检查，本轮未逐个触发真实业务弹窗。
