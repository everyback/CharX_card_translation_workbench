- 应用和导出重新构建当前有效的审核结果；撤回 Lua、模块字段或资源 JSON 的审核后，不再沿用旧译文。模块保存审核基线，独立的逐行修复和正则修改可保留；与旧译文重叠的人工修改阻止应用，保留当前稿并在脚本诊断中继续展示。预设独立编辑结果也保留。
- 资源包从原始字节重建，全部撤回后清除旧草稿引用。新草稿按内容摘要保存，应用数据库事务失败时不覆盖上一次有效文件。

- RISUM/CHARX 模块世界书扫描接收已采用的协议规则，生成协议槽位并保留外壳和保护项；非法分隔符仍阻止应用。
- 区分用户取消、片段转移、人工接管和清空结果。恢复或重试前检查片段归属，避免旧任务抢回新任务已处理的片段；旧范围任务不能在项目重扫后继续执行。
- 前端预设和范围选择变更后提示重新扫描，启动入口和后端同时检查范围。修正快速翻译预设的范围描述，以及“导出阶段会再次尝试”的过期说明。

## 本轮修复

- 翻译引导结合任务状态显示暂停、失败、取消和第二阶段；暂停与取消在同一事务中更新项目状态，避免侧栏继续显示翻译中。
- 项目请求带归属和版本检查，旧项目保存后的刷新不会打断新项目的分页加载，也不会覆盖新项目的报告。
- 显式刷新列表与仪表盘绕过五秒缓存，避免导入、删除后使用旧列表；后台轮询仍使用缓存。
- 任务详情保留当前选择，继续获取暂停、完成后的最终状态。
- 审核和协议编辑只自动更新未修改的输入；人工编辑、取消重译和批量操作失败时保留本地草稿。
- 正则保存成功与命中校验分开展示；错误显示在弹窗内，替换输出冲突时更新基线并保留输入，允许核对后再次保存。
- 正则测试或保存期间锁定对应输入，保存后的诊断刷新不影响保存结果。
