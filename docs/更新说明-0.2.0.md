# 0.2.0 更新说明

本次版本范围为 0.1.9（Git 提交 `3eee872`）之后的全部项目源代码、测试和文档改动；临时测试文件和本地敏感数据不属于发布内容。

## 卡片版本与增量翻译

- 同一项目可导入、切换多个版本，并查看字段新增、变化、移除和匹配歧义。
- 新版本继承基础版本的语言、翻译范围和术语配置，独立保存原始内容、草稿和审核结果。
- 原文未变且通过保护校验的旧译文可复用为待审核稿；支持旧版补译完成后手动补用，不覆盖本版已有编辑和审核决定。
- 世界书字段匹配支持稳定 ID 和条目重排，重复身份不自动猜测。新增版本、扫描及复用记录支持事务回滚。
- 项目库按版本家族聚合，提供版本删除保护与整组删除数量核对。

## 工作台与审核体验

- 重整项目库、侧栏、工作区导航和项目工具入口，新增独立导出页与版本记录页。
- 项目库提供搜索、状态和格式筛选及排序；保留已有项目深度链接。
- 简化审核列表与操作区，保留原文、机器译文、人工定稿对照，改善页面切换时的表单状态保留。
- 统一按钮、输入框、卡片、表格、提示和弹窗样式，覆盖项目、预设、资源、脚本、插件和设置页面。
- 新版本文件选择改为自定义按钮和拖放区域，显示文件名、大小及格式错误；修复“导入并比较”按钮未提交表单的问题。

## 加载、任务与脚本改进

- 翻译内容列表分页展示；项目段落分批加载并报告进度，切换项目时取消过期请求。
- 改善任务详情加载状态与请求切换处理，以及隐藏页面的渲染和导航反馈。
- 优化长 Lua 脚本及内嵌长文本的差异对齐，减少独立修改被错误合并为冲突的情况，并补充回归测试。
- 更新扫描、审核草稿重建、数据库迁移及工作流一致性相关测试。

## 兼容与保护

已有项目迁移为初始版本，保留项目 ID 和已有内容。复用译文仍需审核后才能应用或导出；世界书原始触发词和脚本、变量等保护规则继续生效。各版本保留独立资源包，大型卡片多版本会增加磁盘占用。

本次推进次版本号 `0.1.9 → 0.2.0`，表示新增完整功能与交互流程；尚不将产品定义为 1.0 稳定版。
