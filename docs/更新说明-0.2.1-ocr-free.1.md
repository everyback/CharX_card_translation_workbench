# 0.2.1-ocr-free.1 测试版

移除资源页已无入口的 OCR 后端功能及 Tesseract 依赖，减少桌面包占用。普通卡片与世界书翻译、图片编辑模型、手动上传图片、人工确认与审核后导出继续使用现有流程。

- 删除 OCR 识别与候选编辑接口、候选返回字段、OCR 类型及缓存配置。
- 新数据库不再创建 OCR 表；旧数据库里的历史表和旧缓存不自动删除，便于回退到旧版。
- 移除 `tesseract.js` 及不再需要的传递依赖，锁文件共减少 13 个包。
- 服务端构建前清理旧编译产物，避免已删除的 OCR 文件残留。
- GitHub Actions 检查打包目录中没有 Tesseract 或 OCR 后端文件，再发布测试产物。

测试包仅由 GitHub Actions 的 Nightly 流程生成，正式标签 `v0.2.0` 保留。包体积以云端产物为准。

## 验证

- `npm test`：502 项通过。新增回归验证 OCR 接口返回 404、新库不创建 OCR 表、历史 OCR 表不影响资源检查，以及手动图片的待审、确认导出和撤回恢复原图。
- `npm run desktop:prepare`：通过；服务端输出中没有已删除的 OCR 模块。
- 锁文件与安装依赖树中均没有 Tesseract；版本元数据一致。
- 首次全套测试在临时目录清理时遇到 Windows 文件锁，相关测试单独复跑和全套复跑均通过。
- `npm audit --omit=dev --audit-level=high`：报告 7 项 high，来自已有 Fastify、URI 和 brace-expansion 依赖，本次未扩展修改范围。
