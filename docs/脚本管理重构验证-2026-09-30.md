# 脚本管理编辑与布局重构（2026-09-30）

## 原因与修复

原“脚本修改前后对比”只渲染只读代码，未传入编辑或保存回调；只有语法诊断错误的上下文提供逐行编辑，因此语法修复后编辑入口消失。

- 修改对比提供现存模块 Lua 字段的真实 JSON 路径，当前稿可逐行编辑；继续复用行基线冲突检测、保存及语法校验。原始代码只读。
- 正则 in/out 修改可打开现有规则编辑器；对齐 `$module` 与诊断中的“模块”路径前缀。无对应保存接口的卡片路径明确显示只读原因。
- 页面分成“修改与编辑、诊断与修复、正则规则、名称与别名”四个页签，诊断定位会切到对应区域。
- 对比改为左侧路径列表、右侧单项编辑；搜索覆盖全部路径，每页展示 30 项。列表和代码区域分别限制高度并滚动，窄屏改为纵向布局。
- 编辑未结束时锁定路径、搜索及页签切换，保存失败保留输入；保存提示绑定对应路径。
