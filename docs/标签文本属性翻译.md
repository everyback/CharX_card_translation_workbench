# 标签文本属性翻译

正文和开场白中的自然语言属性会独立扫描为审核项，例如 `data.first_mes · <portrait> @description`。审核通过后按原位置回填属性值；标签名、属性名、引号和其他属性保持原样。属性译文中的引号和尖括号会编码为 HTML 实体，避免破坏标签结构。

白名单配置位于 `config/text-attributes.ts`：

- `common`：跨标签的自然语言属性，默认包含 description、alt、title、aria-label、placeholder、data-tooltip、data-label。
- `byTag`：特定标签的附加属性；不要把 value 之类可能承载运行时值的属性加入通用名单。
- 事件属性以及 chara、state、id、src、href、class、style、path、url、key、type、name 即使被误配，也不放开。

未知属性继续保护，不根据韩文、日文等字符特征自动放开。需要新增属性时，先确认它是自然语言而不是资源键、协议字段或脚本参数，再配置到明确的标签范围。

模板变量、URL 等继续走现有保护规则。漏翻检查沿用源语言、回退语言和目标语言配置；在已识别的文本属性中发现残留时，会报告标签和属性名。源语言与目标语言相同时不报漏翻。

已有项目不会自动改写。加载新版服务后重新扫描，才会出现独立属性审核项；只选择遗漏的属性进行补翻并审核。旧的整段译文也会接受属性残留检查，旧的“整标签保护”不再掩盖其中的自然语言遗漏。

当前不处理无引号属性；代码围栏、HTML 注释和 script/style 内容不提取为自然语言属性。
